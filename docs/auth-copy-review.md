# 注册登录文案走查表

本文档用于记录注册登录相关页面的文案、真实业务状态、用户下一步和需要修改的问题。

原则：

- 先记录，不边走查边零散改代码。
- 文案必须对应真实逻辑，不能只描述理想状态。
- 文案不能暴露邮箱是否已注册等隐私信息。
- 每个状态都要给用户明确下一步。
- 视觉问题不记录在这里，除非它会影响文案理解。

状态说明：

- 待走查：还没有确认。
- 待确认：已记录问题，需要设计或产品确认。
- 需要修改：已确认要改，等待统一修改代码。
- 已修改：代码已改，等待复查。
- 通过：当前文案可接受。
