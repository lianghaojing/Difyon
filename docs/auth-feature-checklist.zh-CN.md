# Auth 功能 Checklist 中文版

这份文件是 `docs/auth-feature-checklist.md` 的中文阅读版，用来让非工程角色快速判断注册、登录、找回密码、账号中心和发布前验收状态。英文文件仍保留为工程追踪原件。

## 状态说明

- Done：已经实现，并且当前代码或实际浏览器验证已经覆盖。
- Blocked：不是代码问题，当前本地环境无法继续，需要外部配置或线上环境。
- Todo：还没完成，或需要继续确认后才能算完成。
- Later：后续增强项，不影响第一版注册登录上线。

## 当前结论

注册登录的程序类和交互类工作已经基本完成。已经通过 Chrome 实际操作验证过注册、邮箱验证、登录、登出、忘记密码、重置密码、旧密码失效、新密码登录、账号中心改昵称/改密码、语言切换和基础键盘可访问性。

现在真正影响合并判断的只剩两类：

- 视觉确认：需要你确认不同屏幕尺寸下页面是否符合设计预期。
- 真实邮件环境确认：需要目标环境配置 Resend 发信域名和真实密钥。
